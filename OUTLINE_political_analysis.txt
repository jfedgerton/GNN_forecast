2. THEORY: EMBEDDEDNESS IN MULTIPLEX NETWORKS (1,500 words)
================================================================================

2.1  Network embeddedness as structural power
     - Hafner-Burton et al. (2009): network approach to international politics
     - Embeddedness ≠ centrality; it captures structural similarity and
       redundancy of position
     - Why position matters: states with similar structural positions face
       similar constraints and opportunities

2.2  The multiplex dimension
     - Maoz (2010): international networks are inherently multiplex
     - Different layers encode different kinds of interdependence
     - Theoretical expectation: some layers reinforce each other (alliance +
       trade = deep integration), others may substitute (IGO membership as
       alternative to bilateral alliance)
     - The GNN's learned attention weights provide empirical traction on
       which layers matter most

2.3  Temporal dynamics
     - International networks evolve: alliances form and dissolve, trade
       patterns shift, institutions expand
     - Static snapshots miss the trajectory — a state gaining embedding
       is substantively different from one losing it
     - The GRU temporal module captures this trajectory explicitly

2.4  Dual-focal counterfactuals: a framework for strategic analysis
     - Traditional counterfactuals ask: "how does removing edge X affect
       state A?"
     - Our framework asks: "how does removing edge X affect state A AND
       state B simultaneously?"
     - This enables identification of:
       * Wedge edges: ties where the effect is asymmetric (helps one, hurts
         the other)
       * Leverage points: ties whose removal/addition maximally shifts
         relative position
       * Synergistic bundles: sets of edges with super-additive effects

2.5  Hypotheses (optional — PA papers can be exploratory)
     H1: Trade ties with middle powers have larger embeddedness effects
         than alliance ties (because trade networks are denser and more
         asymmetric)
     H2: Edge effects are non-additive — losing multiple ties to the same
         partner produces super-additive isolation
     H3: Opportunity-adjusted (residualized) ties tell a different story
         than raw ties — some states appear embedded only because of
         structural opportunity, not genuine integration

4. METHOD (2,000 words)
================================================================================

4.1  Architecture overview
     - Figure 1: Architecture diagram
       Per-layer GCN → Attention Aggregation → GRU → Embedding Prediction
     - Input: multiplex snapshot at time t (5 adjacency matrices + node
       features)
     - Output: predicted embedding vector for each state at time t+1

4.2  Per-layer GCN encoder
     - Each layer gets its own 2-layer GCN (with ReLU, dropout)
     - Handles variable density and missing layers via masking
     - Custom sparse GCN implementation (no PyG dependency required)

4.3  Attention-based layer aggregation
     - Learned softmax attention weights over available layers
     - Masked softmax: layers unavailable in a given year get zero weight
     - Weights are interpretable: which layer types does the model rely on
       most for predicting future embeddings?

4.4  Temporal GRU
     - Sequence of snapshot embeddings → GRU → predicted next embedding
     - Captures how structural position evolves over time
     - Configurable sequence length (default: 5 years)

4.5  Training
     - Multi-component loss: MSE on predicted vs actual embeddings +
       optional contrastive and stability terms
     - Walk-forward training: train on years up to t, validate on t+1
     - Early stopping on validation loss
     - Multi-seed evaluation for stability

4.6  Counterfactual machinery
     - Edge perturbation: remove or add edges for a specific partner in a
       specific layer
     - Forward pass with modified adjacency → counterfactual embedding
     - Embeddedness metrics: mean cosine similarity, centroid distance,
       k-NN density, mean pairwise distance

4.7  Dual-focal counterfactuals
     - Innovation: perturb one edge, measure Δ for BOTH USA and China
     - Four quadrants:
       Q1: both more embedded (shared benefit)
       Q2: USA isolated, China embedded (strategic threat to US)
       Q3: both isolated (shared cost)
       Q4: USA embedded, China isolated (strategic threat to China)
     - Wedge = Δ_USA - Δ_China (positive = favors USA)

4.8  Greedy combinatorial search
     - Problem: testing all edge combinations is exponential
     - Solution: select top-k single edges per objective, test C(k,2) pairs
       + C(k,3) triples
     - Interaction effect = actual combo effect − sum of individual effects
       * Positive interaction = super-additive (synergy: edges reinforce)
       * Negative interaction = sub-additive (redundancy: edges overlap)
     - Computational cost: ~660 forward passes for k=10, max_size=3,
       4 objectives — minutes on CPU

7.2  Methodological contributions

     - Dual-focal counterfactuals as framework for comparative analysis
     - Greedy combo search as scalable approach to interaction effects
     - Learned attention weights as interpretable layer importance

7.3  Limitations
     - Model-based counterfactuals, not causally identified
     - Layer coverage varies by time period
     - DCA data is recent — limits temporal analysis of security cooperation
     - Embedding space is learned, not observed — interpretation requires
       care
     - Computational cost of full counterfactual sweep

7.4  Future directions
     - Extend to directed networks (not just undirected ties)
     - Add more layers (arms transfers, diplomatic exchanges, cyber)
     - Uncertainty quantification (MC dropout, conformal prediction)
     - Apply to other dyadic competition contexts (India-Pakistan,
       Saudi-Iran)
