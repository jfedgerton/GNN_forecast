[x] Multiplex data pipeline (src/gnn_forecast/multiplex_data.py)
    - 5-layer support: offensive alliances, defensive alliances, IGO, trade, DCA
    - Automatic file discovery from data/processed/
    - Missing-layer masking per year
    - Degree-profile node features
    - Tensor conversion for PyTorch

[x] Tie-strength residualization (src/gnn_forecast/preprocessing.py)
    - Python-side FE-proxy residualization (logistic for binary, ridge for continuous)
    - Sender + receiver + year categorical features
    - Optional contiguity feature
    - Note: the R export script already produces FE-residualized layers via
      fixest::feols, which is the preferred approach for the paper

[x] Multiplex temporal GNN (src/gnn_forecast/multiplex_model.py)
    - Per-layer GCN encoders (separate weights per layer)
    - Learned attention-based layer aggregation (softmax over logits)
    - GRU temporal model for next-period embedding prediction
    - Inner-product edge decoder for link reconstruction
    - Falls back to custom GCN if torch_geometric not installed

[x] Training loop (src/gnn_forecast/training.py)
    - Loss = MSE(embedding) + lambda_link * BCE(link) + lambda_smooth * MSE(smooth)
    - Early stopping with patience
    - Checkpoint saving (model weights, embeddings, diagnostics)
    - Autoregressive forecast rollout

[x] Counterfactual simulation (src/gnn_forecast/counterfactual.py)
    - Single-edge knockouts and additions
    - Full model forward pass (not 1-hop proxy)
    - Batch ranking across partners x layers x operations
    - 4 embeddedness metrics: mean cosine, centroid distance, major power
      distance, kNN density
    - Layer-level and overall summaries

[x] Walk-forward backtesting (src/gnn_forecast/validation.py)
    - Train on [start, split_year], test on (split_year, split_year + horizon]
    - Reports embedding MSE, link prediction AUC, USA/China embeddedness
    - Multiple split years supported
    - Saves per-fold diagnostics

[x] Multi-seed robustness (src/gnn_forecast/validation.py)
    - Train with N different random seeds
    - Reports variance in loss, layer weights, embeddedness metrics
    - Saves summary CSV

[x] Baseline comparisons (src/gnn_forecast/baselines.py)
    - Static GNN (encode year t, linear map to year t+1, no temporal memory)
    - Degree-AR (GRU on raw degree features, no graph encoding)
    - Mean baseline (predict training-period mean)

[x] Visualization / table generation (src/gnn_forecast/visualization.py)
    - PCA projections of embeddings (with UMAP fallback)
    - Embeddedness time series for focal states
    - Layer weight comparison tables
    - Loss curves

      - Does it outperform mean baseline (no learning)?
    This demonstrates the value-added of each model component.
